# Changelog

All notable changes to MirrorMod are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

The section of a version is used as the notes of its GitHub release, so every version needs one before it is released.

## [1.0.0] - 2026-11-25

First release, built against ZHM Mod SDK v4.2.1 for game version 3.290.1.0.

### Added

- Every level is shown horizontally flipped, including 47, who becomes left-handed.
- UI, menus and subtitles stay readable.
- Prompts, world markers, off-screen indicators, detection arrows and hit markers are placed and pointed the mirrored way.
- The minimap is mirrored as a whole, the map in the pause menu horizontally or vertically, with readable labels and icons.
- Mouse, sticks, strafing and the SDK's FreeCam are reversed horizontally.
- Left and right audio channels are swapped, including surround pairs.
- The third person camera moves to the other shoulder.
- Toggle key (default `F7`), a settings window in the SDK overlay and `mirrormod.ini`.
- A log file and developer tools for tracing frames, input and the UI.
